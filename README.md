## About CraftMine

CraftMine is a Minecraft-style voxel game designed to run directly in a web browser. Its single-file HTML format makes the project easy to open, share, and explore without a conventional installation process.

The game brings together a broad collection of interactive content, including 46 block types, 36 mobs, and 19 weapons. Multiplayer support adds a shared-play option for users who want to experience the voxel environment with others.
